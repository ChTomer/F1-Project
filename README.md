# F1-Project - Data Analysis Project

## Introduction
Hi, I’m Tomer. I graduated from **NYC Data Science Academy.**  
In this project, I practiced working with Python, Git, and GitHub.

## Project Objectives

- Which country has won the most championships?
- Where does the US rank in Formula One?
- How has Formula One evolved over time?

## Data

The F1 data comes from [Kaggle](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020).  
The dataset was last updated in August 2023.

I also used this data for the [countries list](https://www.kaggle.com/datasets/rinichristy/countries-gdp-19602020).

## Tools

I used several visualization and data analysis tools, including:

`pandas`, `matplotlib`, `seaborn`, `plotly.graph_objects`, `plotly.express`, `squarify`, `Waffle`, `PIL`, and more.

## Getting Started

If you want to run the code, the CSV files are expected under the following path:

`archive/<file_name>.csv`

Make sure the `.ipynb` files are in the same directory as the `archive/` folder.

## Project Structure

I created three separate notebooks, one for each question in the analysis.  
Instead of focusing on individual drivers, I aimed to tell a story about Formula One success through countries.
